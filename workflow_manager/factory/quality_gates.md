# Factory Quality Gates (Manager enforced — no product ships without all 5)

## G1 — Brief (Organiser)
- [ ] Title, buyer, problem, format, price (AUD, GST-inc), SKU assigned
- [ ] No duplicate of existing catalogue (check Airtable Products first)

## G2 — Draft + Fact-check (Formatter → Editor)
- [ ] Full content complete (no placeholder text, no lorem)
- [ ] Prices/dates/claims verified against primary source (<24 months)
- [ ] Aussie spelling + voice; disclaimer present where advice appears

## G3 — Evaluation ≥ 85/100 (Editor, independent)
- [ ] Score content, accuracy, presentation, value-for-price
- [ ] <85 → back to Formatter with notes (max 3 loops, then Manager rules: cut scope or kill)

## G4 — Package verified (Packager)
- [ ] ZIP builds, sha256 recorded, file opens from clean download
- [ ] Cover 1600×2560 + thumb 600×315 present, SKU filenames
- [ ] Free sample carved out (<15% of paid content) with buy CTA

## G5 — Publish checklist (Manager + Accountant)
- [ ] Stripe price live (test mode first), amount in cents double-checked
- [ ] Gumroad listing draft + sample attached
- [ ] 1 test purchase + refund before public links
- [ ] Airtable Products row → Status Done; weekly accountant picks up revenue

**Kill rule:** any product failing G3 three times is cut. A dead product costs a day; a bad one costs the brand.
